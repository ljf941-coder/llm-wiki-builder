# llm-wiki-builder

一个用于构建和改造个人 LLM Wiki 的 Agent Skill。它指导 AI 根据个人生活、学习和工作场景，建立可追溯、可迁移、适合多个 AI 工具协作维护的知识库。

该技能适合需要长期积累和复用个人知识、项目经验与决策的人；它不用于初始化普通软件项目文档。

## 能做什么

- **梳理现状与目标**：检查现有入口、目录、来源、规则和自动化，保留已有数据与工具适配。
- **设计知识结构和权限**：区分原始材料、候选内容、正式知识、用户原话和处理状态，明确修改、冲突及授权规则。
- **整理来源与项目经验**：根据用户选择设计采集、版本识别、去重、提炼和归档流程；项目资料先参考项目入口及知识地图。
- **保留来源与不确定性**：区分事实、AI 整理、个人判断和待确认事项，记录来源、处理状态及覆盖不足的范围。
- **支持安全与迁移**：按要求检查敏感信息，保留经授权的来源快照，检查引用、备份和迁移依赖。
- **协作与自检**：以共享规则为基础适配不同 AI 工具，并通过用户指定的自检会话检查知识库规则。

本仓库提供的是指导 Agent 工作的 `SKILL.md`，不是现成的知识库应用或自动运行的采集服务。具体脚本、接入、调度、审核和备份需要结合环境与授权另行配置和验证。

## 安装

将仓库克隆到支持 Agent Skills 的工具所使用的技能目录，目录名保持为 `llm-wiki-builder`。例如，安装为当前用户的 Codex 技能：

```bash
git clone https://github.com/ljf941-coder/llm-wiki-builder.git ~/.codex/skills/llm-wiki-builder
```

Windows PowerShell：

```powershell
git clone https://github.com/ljf941-coder/llm-wiki-builder.git "$env:USERPROFILE\.codex\skills\llm-wiki-builder"
```

其他工具的技能目录和加载方式可能不同，请参照对应工具的文档。也可下载本仓库，将包含 `SKILL.md` 的文件夹复制到该工具支持的技能目录；安装后按工具要求重新加载技能或重启会话。

## 使用

在支持技能的 AI 助手中，以自己的目标描述任务，例如：

> 使用 llm-wiki-builder 帮我从零设计个人知识库，整理工作、学习和生活资料。先检查我的需求，再给出可实施的结构。

也可以改造现有知识库：

> 使用 llm-wiki-builder 检查当前知识库的入口、来源和整理流程，保留已有内容，补充可追溯和自检机制。

说明现有目录、可访问的来源、希望采集的范围，以及是否允许 AI 直接归档。涉及用户原话、敏感资料或已有文件的修改时，遵循知识库现有规则和用户授权。

## 工作流程

1. 了解目标、使用场景和既有知识库。
2. 设计共享入口、区域规则、来源与状态管理。
3. 按实际需要实施采集、整理、关联、检索和备份。
4. 检查链接、来源、重复运行、失败处理和不确定事项。
5. 汇报实际完成的工作、验证结果和仍需配置的部分。

若需要持续检查规则，可由用户在知识库项目中创建专属自检会话并授权后续使用。已有会话带有历史上下文，不能当作全新会话的冷启动测试。

## 边界

工具能访问哪些会话、文件和外部来源，取决于实际连接与权限；安装技能本身不会自动接通来源或开启后台任务。对来源不足的内容应标为待确认，敏感信息检查也不能保证覆盖所有形式。
